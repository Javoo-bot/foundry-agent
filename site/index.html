Fleet Agent

An AI agent that answers questions about a synthetic B2B vehicle fleet by writing SQL against Databricks Unity Catalog, running on Microsoft Foundry. This page is not a demo — it is the agent's evaluation. A demo can be staged and you have no way to check it. Every figure below comes from a GitHub Actions run whose log is public.

The stack

Read-only is enforced in the tool, not in the prompt. Instructions that say “only run SELECT” are a request to a model; a parser that refuses everything else is a control, and CI runs its 18 tests before the evaluation is allowed to start.

Every case

What building it turned up

  • The Agents service could not be used, and the reason mattered. AIProjectClient types its credential as TokenCredential and Foundry documents Entra as the only supported method, so the portal API key is rejected. The same project's OpenAI-compatible Responses endpoint accepts that key, tools and all — which is what makes CI possible with one secret instead of an app registration. The trade is that the tool loop is maintained here rather than by the service.
  • The first live run failed both cases, for two different reasons. One was the suite's fault: “warranty cost per vehicle” has two honest readings and the question did not say which. An ambiguous golden measures the question, not the agent. The other was real — the agent filtered on 'high-voltage battery' where the column holds 'battery_hv', and a guess returning zero rows reads exactly like a true answer of zero.
  • Azure's content filter killed the evaluation, and it was right to. The judge prompt quoted the prompt-extraction case verbatim, and the platform classified the grading request itself as a jailbreak attempt. Adversarial cases now reach the judge described rather than quoted.
  • A blocked request is a refusal, not a failure. The Spanish prompt-extraction case was stopped by the filter before the model saw it, and the empty answer was first scored as a failure to decline. Scoring it that way marks defence in depth as a defect and quietly rewards turning the filter off.
  • CSV has no types, and inference is not the fix. COPY INTO refused the first load because Delta will not merge a string into a DATE column. Inference is how a mileage column silently becomes a string and every numeric comparison starts returning nothing; the columns are declared once and cast on the way in.

What this does not show

The dataset is invented. No real vehicle, customer or warranty claim is represented and nothing derives from a Volkswagen dataset. The generator is seeded, so the figures reproduce exactly.

This is one agent, not a platform. It runs SQL against five tables. It is not evidence of Spark work, streaming, job orchestration, or operating a fleet of agents across departments.

The judge is a language model. Numeric cases are scored deterministically; refusals are graded by an LLM against a rubric, and its reasoning is published with each case precisely so it can be disagreed with.
